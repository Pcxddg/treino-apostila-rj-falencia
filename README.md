# Apostila RJ e Falência · Treino para a prova 18/11

Página única (single-file HTML) com trilha de estudo em 11 níveis sobre **Recuperação Judicial e Falência**, baseada na apostila de 16 páginas do Prof. Walber.

- Arquivo: `index.html` (autossuficiente, sem dependências externas além de uma fonte do Google Fonts)
- Recursos: trilha completa / reta final, exercícios com correção passo a passo, simuladão, glossário, cola de prazos, tema claro/escuro e progresso salvo no `localStorage`
