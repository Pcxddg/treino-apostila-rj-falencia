# Apostila RJ e Falência · Treino para a prova 18/11

Página de estudo interativa sobre **Recuperação Judicial e Falência**, baseada na apostila de 16 páginas do Prof. Walber.

## Duas versões (convivem no mesmo site)

- **Original** → `/index.html`
- **Nuevo** → `/index2.html`

O botão **Original / Nuevo** no cabeçalho troca de versão. Cada uma guarda o progresso separadamente no navegador (chaves `treino-apostila-rj-v1` e `treino-apostila-rj-v2`), então dá para usar a que quiser sem perder nada.

- Autossuficiente: um único arquivo por versão, sem dependências (só uma fonte do Google Fonts)
- Trilha completa / reta final, correção passo a passo, simuladão, glossário, cola de prazos, tema claro/escuro
